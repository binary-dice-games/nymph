# nymph element reference

Generated by `nymph schema --markdown --paged docs` (every build of
`nymph` refreshes it; a test checks that these files match the
program). Do not edit by hand.

Every element is a mapping with a `type`, any of the fields below, and
`children` when it takes them. List fields also take a `$column`
(or `$table:column`) reference; text fields take one too (the cells
joined by newlines).

The reference is in pages, one per kind of figure, so that only the
page of the figure being built needs reading. Open the page of the
element you put under `root`: it holds that element and every type
that goes inside it (a class diagram's classes and relations, a
plot's series, a screen's windows and widgets). Elements that fit in
many places (layouts, labels) have a page of their own, linked from
the pages that take them.
